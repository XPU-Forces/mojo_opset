# KPool A2 并行验收版更新（2026-11-13）

本报告随 PR #533 同步用户指定的 A2 并行验收源。底层 5 个 Triton 函数的 AST 与已验证独立实现一致；公开接口、custom-op schema/FakeTensor、host 分派与 launch 参数保持原实现。A5 文件未改动。

验收源 SHA256：`a71709ed30690e95a0370939f2c3be39d16d514e1f06aa3a53a660546ee911e8`。整合文件 SHA256：`017f8ec504ea674aee46fee9f1f229b7ee662db8d2bb86468aed6074aa06db8e`。源码来源为 2026-11-13 全量验收采集；完整原始 CANN 目录、kernel_details.csv 和独立重算回执保留在开发任务归档中。此报告引用已有采集，本次没有启动设备复测。

## 实现变更

- P16 的 8 行路径在 N≥640 时缓存 APE 并预取 K/score，当前 tile 的计算与后续输入搬运交叠。
- 为实际生成 scale 的 INT32 tensor 指定独占存储和双缓冲，FP8 payload 同时使用双缓冲，使后续 Vector 计算与之前的 MTE3 写出交叠。
- 连续槽位、同页且 scale 对齐的 8 行 tile 合并连续写出，其余槽位继续使用逐行地址。
- FP8 亚正规分支恢复验收源中的 FP32 幅值比较；保持与验收源码 AST 一致。

## 验证范围与历史收据

验收独立实现已有 BF16 标准精度 27/27、补充检查 12/12、FP8 编码边界 1014 项零错误；26 个非空用例及独立峰值均在三组中通过非 Scalar 门禁。

按用户要求，图编译与缓存副作用、分派边界、最终公开接口完整性能这三项本次不复测。仓库历史 78/78 及公开接口两轮 12 例采集属于 e21f88b 的旧 A2 实现，不能作为本次整合版本的新设备测试结论。A5 实现与当时相同，仍可引用其既有测量；A5 历史 L20/A5 设备 kernel 几何平均 0.502058×，GPU 基线没有重跑。

本轮静态检查包括 Python AST、Ruff lint/format，以及 JIT AST 与验收源逐函数一致、非 JIT 封装 AST 不变、launch/host 分派一致。没有把静态检查写成板端复测通过。

## 仿真与计数限制

同一验收源的 [4096,16,128] BF16/core0 仿真确认 12/12 跨轮边界发生下一轮 Vector 值计算与上一轮 MTE3 重叠；输入预取交叠保持。MTE3→Vector 等待区间总和 1.843333→0.097222 µs，仍保留一次正等待。这是仿真指令区间，不是设备时延或 PMU 独占停顿。原仿真完整 END/bin 后子进程出现 SIG11，按带运行警告的采集保留，不能声称干净退出。

独立峰值额外 40 个 Memory/L2 launch 已核对设备/stream/task 与清理操作。输入 K+score 共 512 MiB；L2 Hit Rate 原始字段为 N/A，未补造命中率，也没有仅凭 Vector ratio 宣称硬件极限。
